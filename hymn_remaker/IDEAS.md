# Ideas & Explorations
- What if we port the `app.py` UI into a Next.js / React app, and package the backend as a FastAPI service?
- Pivot the `tts_generator.py` to use Suno.ai or Udio if an official API releases, creating true "singing" tracks rather than spoken-word tracks from ElevenLabs.
- Dynamic prompt generation using an LLM based on the MIDI's metadata (e.g. if the MIDI is fast, generate "upbeat house" automatically).
- Webhook functionality to auto-post the YouTube link to Twitter/Discord upon generation.
