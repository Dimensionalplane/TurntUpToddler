# Changelog

All notable changes to this project will be documented in this file.

## [1.7.2] - Current
### Added
- Native C++ `HymnPlayer` engine utilizing FluidSynth.
- Unit tests for the `HymnPlayer` engine.
- A Makefile to compile the native tests.
- Comprehensive AI agent documentation update (UNIVERSAL_LLM_INSTRUCTIONS.md, AGENTS.md, CLAUDE.md, etc.) as requested.
- `VISION.md`, `ROADMAP.md`, `MEMORY.md`, and `DEPLOY.md` extensive updates.

## [1.7.1] - Previous
### Added
- `--daemon` mode using watchdog for automatic processing.
- `--create-shorts` flag to generate 15-second vertical clips.
- Local DALL-E image caching.
- FFmpeg subtitle burn retry loop with ASCII sanitization.
